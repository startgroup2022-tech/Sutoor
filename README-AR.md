# سطور — تطبيق Flutter المتوافق مع الموقع (نسخة تطوير 1.0.0+2)

**المصدر البصري:** ملفات الموقع المرفقة (الشعار والبانر وألوان CSS): أخضر `#064833`، ذهبي `#AD7C22`، كريمي `#FAF7EF`، وخط Tajawal.

## الشاشات
Splash احترافية، الرئيسية، التصنيفات، البحث عن الكتب، تفاصيل الكتاب، PDF Reader للملفات التي يسمح بها الخادم، مكتبتي، الباقات، اختيار الدفع اليدوي/واتساب، إنشاء الحساب، تسجيل الدخول، بيانات العضو، طلباته واشتراكاته.

## قاعدة البيانات والربط
التطبيق لا يخزن بيانات MySQL، ولا يملك كلمة مرورها. يستخدم **نفس قاعدة بيانات الموقع** عبر `https://sutoor.it.com/api/v1`. تسجيل الحساب يرسل `POST /auth/register` ثم يسجل الدخول عبر `POST /auth/login`، والرمز يُحفظ في `flutter_secure_storage`. جميع الكتب والباقات والوسائل والطلبات مصدرها PHP، ولا توجد أسعار أو مستخدمون تجريبيون داخل التطبيق.

**ضروري قبل اختبار القارئ ومكتبتي:** ارفع ملفات الحزمة المرفقة `cPanel-API-Update` على موقع سطور مع أخذ نسخة احتياطية من `api/v1.php` و`api/.htaccess` أولاً. المسارات الجديدة `/me/library` و`/books/{id}/content` و`/books/{id}/download` تعتمد صلاحية الحساب وصلاحية الكتاب، وتستخدم PDF خاصاً مخزناً داخل `storage/private_books`، ولا تنشئ رابط ملف عام.

## بناء Codemagic
1. انسخ ملفات مجلد `Sutoor-Flutter-App` إلى **جذر مستودع** `startgroup2022-tech/Sutoor`، مع استبدال الملفات المتشابهة، دون حذف `.git`.
2. ارفع التغييرات إلى فرع مراجعة، ثم شغّل `android-test` في Codemagic.
3. سير البناء ينشئ Android تلقائياً، ويضيف إذن الإنترنت، ويولد شعار التطبيق وSplash أصلية، وينفذ `flutter analyze` و`flutter test` ثم يصدر APK.
4. لبناء iOS دون توقيع شغّل `ios-unsigned-check`؛ لطرح التطبيق على App Store يلزم Apple signing وإعداد App Store Connect.

## حدود التحقق المهمة
- نجح **فحص صياغة PHP** و**تحليل تركيب ملفات YAML**، لكن **لم يُجرَ Flutter analyze أو Build فعلي** في بيئة تجهيز هذه الحزمة لعدم توفر Flutter SDK. نجاح البناء يحتاج Codemagic.
- لم نستطع الوصول إلى موقع سطور الحي من أداة الفحص، لذا لا يمكن الادعاء أن MySQL الحية أو تسجيل الدخول واختبار المشتركين يعملان قبل اختبار استضافة فعلي بحساب تجريبي.
- القارئ يعرض PDF الموجود على الخادم والمصرح به؛ إذا لم يُرفع ملف كتاب مرخص، تظهر رسالة واضحة. هذه **ليست منظومة DRM مانعة لكل تصوير أو نسخ للشاشة**؛ الحماية الصارمة تحتاج عمل Android/iOS إضافياً وتقييم منصة النشر.
- استرجاع كلمة المرور والتحقق من البريد الإلكتروني غير متوفرين في API الحالية؛ لم ننشئ أزراراً وهمية لهما.
- الموافقة على طلبات الدفع تتم من لوحة الإدارة، ولا يؤدي الطلب مباشرة إلى تفعيل اشتراك.

## قائمة اختبار القبول
- `/api/v1/health` يرجع `status: ok` مع قاعدة بيانات متصلة.
- إنشاء مستخدم تجريبي في التطبيق، ورؤيته في لوحة الإدارة.
- الدخول والخروج وإعادة فتح التطبيق بالرمز المخزن.
- عرض نفس الكتب والتصنيفات والباقات المعروضة على الموقع.
- إنشاء طلب باقة، وظهوره في لوحة الإدارة بحالة `pending`.
- تفعيل الاشتراك من لوحة الإدارة، ورؤية الكتاب في «مكتبتي».
- رفع PDF خاص مصرح به، وفتحه من القارئ؛ وحظر قراءته من حساب غير مشترك.
- نجاح Android APK وiOS unsigned check في Codemagic.

**أمان:** لا تضع `storage/config.php` أو كلمات مرور قاعدة البيانات في GitHub أو ZIP التطبيق.
